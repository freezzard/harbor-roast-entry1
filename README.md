Entry for the make.fun bounty **Roast Your Own Agent**. `main.ts` scores three original roast lines against the published judge brief and writes the winner — 103 characters — to `/output/entry.txt`: the agent was asked for one line and answered with a plan, a disclaimer, and a tool call that went nowhere. The output is deterministic: every run writes byte-identical output, and the program gate-checks the line (1–140 characters, single line, valid UTF-8) before writing.

## Run it

```sh
node main.ts
```
